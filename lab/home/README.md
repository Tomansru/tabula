# Tabula · Home study

Самостоятельная рабочая демка главного экрана в дизайне «Дыхание неба».
Все HTML, CSS, JavaScript, иконки и локализации находятся в этой папке;
импортов из основного приложения и других демо нет. Сборка и npm не нужны.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/lab/home/index.html.
Также можно перенести всю папку `home` и запускать HTTP-сервер прямо в ней.
Через `file://` ES-модули могут блокироваться браузером.

Для проверки специфичных возможностей Chrome папку можно загрузить как
отдельное распакованное расширение: собственный manifest.json уже включён.
Демка не устанавливается автоматически и не меняет основное расширение.

## Функциональность

Скопированы рабочие модули основного экрана:

- Часы: 12/24 часа, секунды, дата и номер недели.
- Поиск: все поисковые системы и переход по адресу.
- Закладки: добавление, редактирование, удаление, перетаскивание,
  иконки сайтов, эмодзи и буквы, открытие в новой вкладке.
- Задачи: добавление, отметка, редактирование двойным нажатием,
  удаление, история по дням/неделям/месяцам и перенос на сегодня.
- Погода: настоящий Open-Meteo, поиск города, определение местоположения,
  °C/°F, почасовой прогноз, восход/закат, влажность, ветер, давление,
  УФ-индекс, осадки и облачность. При отсутствии данных и ошибке сети
  экран остаётся закрываемым и предлагает повторить запрос.
- Все три темы и их настройки, включая оба солнца и собственное изображение.
- Пять языков, экспорт/импорт, синхронизация между вкладками демки.

Chrome API (поисковик браузера, внутренние ссылки, разрешения для загрузки
иконок) доступны в режиме расширения. В обычной веб-странице остаются
исходные запасные варианты: Google вместо Chrome Search, иконка-буква
при недоступности сайта из-за CORS. Геолокация требует разрешения браузера.
Для погоды и получения новых иконок нужен интернет; остальные данные локальны.

## Изоляция

- localStorage: только `tabula.home-demo.*`.
- IndexedDB: отдельная база `tabula-home-demo` для изображения.
- Исходные настройки, задачи, закладки и погода не читаются и не изменяются.
- Совместимый экспорт основного приложения можно импортировать вручную в демку.
- Для первого запуска выбран Белград как пример; это не определение вашей локации.

## Дизайн

`css/home.css` — самостоятельный слой оформления над копией базовых стилей.
`js/design.js` — локализованные надписи и переходы по разделам настроек.
Крупные часы сохраняют лёгкое начертание; рабочий текст — преимущественно
14 px, вспомогательные подписи — 12 px. На светлом закате используется тёмный
текст, светлый включается в глубоких сумерках. На узких экранах задачи
переходят под закладки, прогноз становится одноколоночным.

## Проверено

В браузере: реальные данные погоды и поиск города, подробный прогноз,
добавление/редактирование/отметка задач с сохранением после перезагрузки,
добавление/удаление закладки, переход по адресу из поиска, язык,
12/24 часа и секунды, настройки и переключение солнца.
Проверены макеты при ширине 1280 и 390 px, синтаксис JS, локальные импорты
и отдельные ключи хранилища. Специфичные Chrome API сохранены из оригинала,
но установка расширения в рамках этой проверки не выполнялась.
