# Store listing

Text for the **Store listing** tab of the Chrome Web Store dashboard. The name and the short description
(summary) come from `_locales/*/messages.json` inside the zip, so they are not repeated here.

## Fields

| Field | Value |
|---|---|
| Category | Productivity → Tools |
| Language | English (default), with Русский, Deutsch, Español and Français added as localized listings |
| Store icon | `icons/icon128.png` (taken from the zip) |
| Screenshots, 1280×800 | `store/screenshots/1-morning.jpg` … `5-evening-cards.jpg`, in this order |
| Small promo tile, 440×280 | `store/promo/small-tile-440x280.jpg` |
| Marquee promo tile, 1400×560 | `store/promo/marquee-1400x560.jpg` (optional; used if the store features the extension) |
| Homepage URL | https://github.com/Tomansru/tabula |
| Support URL | https://github.com/Tomansru/tabula/issues |
| Mature content | No |

## Description

### English

```
Tabula replaces the new tab with a calm, fast home screen.

• A clock over a living sky. The Breathing sky theme follows the real position of the sun for your location and season (morning light, golden hour, twilight) and shows real stars at night: Polaris, the Big Dipper, Orion.
• Weather at a glance, and a forecast window with the rest of the day hour by hour, the sun's path, wind, humidity, pressure, UV and precipitation.
• Bookmarks as clean tiles with site icons, emoji or letters. Drag to reorder, drop a link to add.
• Today's tasks. Every day starts with a fresh list; unfinished items stay in a history that folds by week, month and year, and move to today in one click.
• Search with Google or the engine you prefer, and the date with its week number.
• Make it yours: Airy or Classic type, quiet captions in the corners, cards behind the widgets, light and dark that follow the sun, or your own picture with dim and blur.
• In English, Russian, German, Spanish and French.

Private by design: no accounts, no analytics, no trackers. Everything stays in your browser. The only requests go to the weather service (Open-Meteo) and, when you ask for a sharp bookmark icon, to that one site.

Open source: https://github.com/Tomansru/tabula
```
